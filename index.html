01

디미고를 소개하는 키네틱 타이포 쇼릴

★☆☆12초

원본 프롬프트는 한 줄("15초 쇼릴, 최대한 보여줘"). Prompt Motion에서 가장 많이 복사된 프롬프트. 한 줄 프롬프트와 장면 지정 프롬프트의 결과 비교.

참고 영상 · Bold kinetic type showreel ↗
모션 레퍼런스: https://www.prompt-motion.com/shneural-2abdfa
위 영상의 굵은 글자, 강한 색 대비, 빠른 템포를 참고해 아래 장면을 제작해줘.
링크를 직접 확인할 수 없으면 아래 설명만을 기준으로 진행해줘.

12초 분량의 키네틱 타이포그래피 학교 소개 쇼릴을 만들어줘.
주인공은 한국디지털미디어고등학교, "DIMIGO"다.
화면에 나오는 학교 정보(학교명, 학과명)는 사실만 쓰고, 숫자·수상 실적·순위는 지어내지 마.

[비주얼 스타일]
- 배경: 오프화이트 ↔ 거의 검정 두 가지만 장면마다 교차
- 강조색: [내가 고른 색 1개] (예: 비비드 오렌지)
- 폰트: 아주 굵은 고딕 1종 + 코드용 고정폭 1종

[장면 구성]
- 0~2초: 터미널 커서가 깜빡이다 "DIMIGO"가 한 글자씩 타이핑 → 글자가 화면을 꽉 채우게 확대
- 2~5초: 글자들이 쪼개져 4개 학과 이름으로 차례로 재조립
  ("e-비즈니스과", "디지털콘텐츠과", "웹프로그래밍과", "해킹방어과")
- 5~8초: 각 학과 이름이 그 학과를 상징하는 도형으로 변형
  (e-비즈니스=상승 그래프, 디지털콘텐츠=재생 버튼, 웹프로그래밍=</>, 해킹방어=방패)
- 8~10초: 네 도형이 가운데로 합쳐져 한 문장으로 "[학교를 한 줄로 표현하는 문구]"
- 10~12초: "DIMIGO / 한국디지털미디어고등학교" 엔드 카드, 첫 화면의 커서로 돌아와 루프

[모션 연출]
- 글자는 개별 글자 단위로 움직이게
- 모든 장면은 이전 장면의 글자/도형이 변형되어 이어지게 (컷 금지)
- 배경 전환은 화면 속 글자나 도형에서 원이 퍼지며 바뀌게
- 박자마다 화면에 변화 1개 이상

[사운드 디자인]
- 타이핑: 기계식 키보드 틱
- 단어 착지: 묵직한 타격음
- 엔드 카드: 짧은 스탭

[배경음악]
- music/01_bgm.mp3 파일이 있으면 그 음악을 사용해줘 (Pixabay 등에서 내려받아 넣기)
- 원곡 표기 예: "Funky Happy Day Light" / Drift_Sound / https://pixabay.com/music/funk-funky-happy-day-light-473457/
- 파일이 없으면 120 BPM 펑키한 드럼·베이스·코드 그루브 음악을 코드로 직접 합성해줘 (기존 곡 멜로디 사용 금지)

[금지]
- 장면과 관계없는 글로우, 파티클 폭발, 렌즈 플레어, 화면 흔들림
- 아무 의미 없는 크로스페이드 전환 (모든 장면은 앞 장면에서 자라나게)
- 과한 바운스 이징 (스프링은 아주 작은 오버슈트까지만)
- 화면 모서리의 장식용 HUD 텍스트
- 1초 넘게 아무 변화 없는 구간 (마지막 2초 제외)
- 템플릿처럼 보이는 모든 것

[제작 방식]
- 단일 HTML 파일, 모든 화면은 seek(t) 함수에서 시간 t만으로 계산해줘
  (CSS transition·타이머·Math.random 금지 → 어느 프레임을 다시 렌더해도 똑같이 나오게)
- Playwright로 30fps 프레임을 캡처하고 ffmpeg로 MP4를 만들어줘
- 외부 이미지 없이 코드만으로 오브제를 그려줘

[배경음악]
- music 폴더에 배경음악 mp3가 있으면 그 파일을 사용해줘 (파일명은 위 [배경음악] 참고)
- 파일이 없으면 위 [배경음악]에 적힌 분위기대로 음악을 코드로 직접 합성해줘 (기존 곡 멜로디 사용 금지)
- 배경음악은 효과음이 잘 들리게 낮추고, 시작·끝에 짧은 페이드

[출력]
- 1920×1080 / 30fps / H.264 / AAC 오디오 포함
- MP4 + 주요 장면 키프레임 미리보기 이미지

[최종 검수]
- 오디오 트랙과 배경음악 신호가 실제로 들어갔는지 확인
- 화면과 효과음 싱크 확인
- 화면에 나온 사실(숫자, 연도, 용어)이 정확한지 다시 확인
- 금지 목록 효과가 들어갔으면 제거
02

무차별 대입을 막는 토큰 버킷

★★☆15초

"캔버스만, 라이브러리 없이, 모든 프레임은 시간의 순수 함수"라는 제작 방식 지정. 실제 렌더링에서 프레임이 튀지 않게 하는 핵심 기법.

참고 영상 · Token bucket rate limiter ↗
모션 레퍼런스: https://www.prompt-motion.com/parkerrex-1a54fe
위 영상처럼 토큰 버킷을 시각화하되, 로그인 무차별 대입 방어 상황으로 바꿔줘.
링크를 직접 확인할 수 없으면 아래 설명만을 기준으로 진행해줘.

15초 분량의 다이어그램 설명 영상을 만들어줘.
대상은 서버를 직접 만들어 본 적 없는 고등학생이다.
Canvas만 사용, 라이브러리 금지, 모든 프레임은 시간 t의 순수 함수로 그려줘.

[설정 — 화면 수치와 동작이 정확히 일치해야 함]
- 버킷 용량 5토큰, 1초에 1토큰씩 다시 채워짐
- 로그인 시도 1회 = 토큰 1개 소모
- 토큰이 0이면 요청은 "429 Too Many Requests"로 거절

[비주얼 스타일]
- 배경 짙은 남색, 버킷은 반투명 유리 원통, 토큰은 금색 코인
- 왼쪽: 로그인 요청 화살표가 들어오는 입구 / 오른쪽: 서버
- 정상 사용자 = 파란 요청, 공격 봇 = 빨간 요청

[장면 구성]
- 0~3초: 버킷에 코인 5개가 차 있고, 위에서 1초마다 코인이 하나씩 떨어지는 구조 소개
- 3~6초: 파란 사용자가 2번 로그인 → 코인 2개 소모, 서버 "200 OK"
- 6~10초: 빨간 봇이 0.1초 간격으로 연타 → 코인이 순식간에 바닥 → 이후 요청은 버킷 앞에서 튕겨나가며 "429"
- 10~13초: 화면 아래 그래프: x축 시간, y축 남은 토큰 (봇 공격 구간에서 0에 붙어 있음)
- 13~15초: 정리 문구 "빠르게 시도할수록 빨리 막힌다"

[모션 연출]
- 그래프 선은 버킷 속 코인 개수와 같은 값으로 실시간 그려줘
- 튕겨나가는 요청은 짧게 붉게 표시되고 사라지게

[사운드 디자인]
- 코인 리필: 맑은 "띵", 토큰 소모: 코인 소리
- 429 거절: 낮은 버저 (연타 구간은 겹치지 않게 볼륨 조절)

[배경음악]
- music/02_bgm.mp3 파일이 있으면 그 음악을 사용해줘 (Pixabay 등에서 내려받아 넣기)
- 원곡 표기 예: "Science Technology Ambient Techno — Drumless Ambient Loop" / Musinova / https://pixabay.com/music/ambient-science-technology-ambient-techno-drumless-ambient-loop-611598/
- 파일이 없으면 드럼 없이 잔잔한 앰비언트 테크노(110 BPM 안팎) 음악을 코드로 직접 합성해줘 (기존 곡 멜로디 사용 금지)

떨어지는 공이 연주하는 음악 기계

★★★20초

원본은 "모든 음이 눈에 보이는 충돌에서 나오는 45초 음악 기계". 악기 배치도처럼 정밀한 화면, 소리와 화면이 1:1로 맞물리는 싱크 설계.

참고 영상 · Collision-driven music machine ↗
모션 레퍼런스: https://www.prompt-motion.com/kamstudiolabs-447565
위 영상처럼 발사대에서 튀어 나온 공이 악기에 부딪힐 때마다 음이 나는 정밀한 음악 기계를 참고해줘.
링크를 직접 확인할 수 없으면 아래 설명만을 기준으로 진행해줘.

20초 분량의 음악 기계 영상을 만들어줘.
모든 음은 화면에서 보이는 충돌 순간에만 나와야 하고, 별도의 배경음악은 쓰지 않는다.

[비주얼 스타일]
- 전체를 3D 공간으로 구성: 악기 3단이 비스듬한 3D 무대 위에 놓이고, 공은 실제 3D 포물선으로 날아감
- 카메라는 정면 설계도 시점에서 시작해 비스듬한 3D 시점으로 돌아 들어갔다가 다시 전체로 빠짐
- 배경: 짙은 남색, 아주 옅은 설계도 격자
- 3단 악기 배치
  · 위: 글로켄슈필 건반 11개 (C5~D6, 건반 아래 음 이름)
  · 가운데: 마림바 건반 18개 + 건반 아래 길이가 다른 공명관
  · 아래: 베이스 바 8개 + 드럼(스네어, 킥) + 심벌(하이햇, 크래시)
- 각 단 양 끝에 공을 쏘는 발사대(회전하는 포신)와 공을 받는 컵
- 공: 금색으로 빛나는 작은 구슬, 지나간 자리에 짧은 꼬리
- 왼쪽 위 제목 "낙하하는 공을 위한 연습곡" + 작은 글씨 "D minor → D major · 156 bpm", 오른쪽 위 "경과 시간 / 20.0" 과 "친 음 개수"

[장면 구성]
- 0~4초: 인트로 — 글로켄슈필만 연주, 발사대가 공을 하나씩 쏨
- 4~9초: 마림바 합류, 공 2~3개가 동시에 날아다님
- 9~14초: 베이스 바와 드럼 합류, 카메라가 마림바 쪽으로 천천히 다가감
- 14~18초: 클라이맥스 — 모든 악기 동시 연주, D 장조로 전환, 크래시 심벌 2회
- 18~20초: 마지막 공 하나가 킥 드럼을 쳐서 끝, 카메라가 전체 기계로 물러나며 정지

[모션 연출]
- 먼저 악보(음 높이·시각)를 정하고, 그 시각에 정확히 충돌하도록 포물선 궤적을 역산해줘

- 영문 띠만 천천히 흐르며 마무리해줘.

[모션 연출]
- 장면 전환은 컷 없이 카메라 이동(앞으로 날아가기, 옆으로 이동, 살짝 돌아보기)으로 이어줘.
- 음악의 킥과 임팩트에 맞춰 화면이 순간적으로 확대되는 줌 펀치를 넣고, 카메라가 비행할 때는 살짝 기울어지게(롤) 해줘.
- 카메라 궤도를 크게 잡고 글자 두께를 충분히 줘서 입체감을 강하게 보여줘.
- 글자는 깊은 곳에서 날아오기, 바닥에서 일어서기(플립), 옆에서 회전하며 들어오기 등 3D 움직임으로 등장시켜줘.
- 읽어야 하는 순간에는 글자가 카메라를 거의 정면(±15° 이내)으로 바라보게 해서 가독성을 지켜줘.
- 모든 글자에 같은 효과를 반복하지 말고 장면마다 움직임을 달리해줘.
- 중요한 글자는 읽히는 동안 위치를 안정적으로 유지해줘.
- 불필요한 회전이나 과도한 번쩍임은 피하고, 글자와 도형의 움직임으로 에너지를 표현해줘.
- 화면 전환과 강조 동작을 음악의 비트에 맞춰줘.

[사운드]
- 영화 예고편처럼 임팩트 있고 강렬한 일렉트로닉 배경음악을 사용해줘.
- 장면이 바뀌는 순간(1초, 3초, 6초, 10.5초, 12초)마다 상승음(라이저) → 묵직한 임팩트(서브 붐 + 금관 브람 + 크래시)를 넣어줘.
- 거친 베이스와 넓은 코드 스탭, 16분 하이햇, 킥마다 베이스가 눌렸다 올라오는 펌핑 효과를 넣어줘.
- 10~10.5초는 스네어 롤로 긴장을 모았다가 10.5초에 드롭해줘.
- music/11_bgm.mp3 파일이 있으면 그 음악을 사용해줘 (Pixabay 등에서 내려받아 넣기, 원곡 표기: 곡 제목 / 작곡자 / 링크)
- 파일이 없으면 위 설명대로 드럼·베이스·신시사이저를 코드로 직접 합성해줘.
- 특정 기존 곡의 멜로디는 재현하지 말아줘.
- 커서 클릭에는 짧은 클릭음, 큰 글자 등장에는 짧은 타격음, 장면 전환에는 가벼운 전환음을 넣어줘.
- 배경음악이 효과음을 덮지 않도록 음량을 조절해줘.
- 시작과 끝에는 짧은 오디오 페이드를 적용해줘.
